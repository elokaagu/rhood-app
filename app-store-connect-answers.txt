3. ACCOUNT DELETION VIDEO  (App Review Information → Attachment)
==================================================
Apple asked for a recording on a PHYSICAL device showing: creating a new account
(or signing in with the demo account) → navigating to deletion → the complete
flow to confirmation. Use a NEW account, not the demo account, because this
deletes it. Record on a real iPhone (Control Centre → Screen Recording):
  1. Install build 443 from TestFlight. Start recording.
  2. Sign Up with a new email (or Sign in with Apple) and get into the app.
     If it lands on the waitlist screen, delete from there — that counts too.
  3. Tap the menu (top right) → Settings → Account → Delete Account.
  4. Tap Delete Account to confirm → the app returns to the sign-in screen.
  5. Try to sign in again with the same login → it fails (account is gone).
Attach the .mp4 in App Review Information (Attachment), AND reply to the
rejection message in App Store Connect with the same video.
